# Module Screen Design

## Design Rule
Every module follows the same standard:
- Add
- View
- Edit
- Delete
- Search
- Filter
- Export

## Dashboard
- Farm summary
- Plant count
- Crop stage
- Tasks
- Alerts
- Quick actions

## Activity Module
Fields:
- Date picker
- Time picker
- Activity type
- Product/material
- Quantity
- Cost
- Notes
- Photo attachment

## Spray Module
Fields:
- Spray date/time
- Product
- Company
- Target disease/pest
- Dose
- Weather condition
- Result observation

## Irrigation Module
Fields:
- Date
- Start/end time
- Water quantity
- Drip details
- Sensor readings

## Fertigation Module
Fields:
- Fertilizer selection
- Dose
- Method
- Cost
- Application history

## Inventory Module
Fields:
- Product
- Company
- Purchase
- Stock balance
- Expiry

## Reports Module
- Cost analysis
- Input usage
- Disease history
- Yield analysis
- Profit report

## Future Ready
All screens should allow future fields and feature expansion without redesigning the complete application.
