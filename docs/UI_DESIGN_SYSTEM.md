# UI Design System Specification

## Purpose
Create a modern, simple and farmer-friendly Android interface.

## Design Principles
- Easy operation with minimum steps
- Clear information display
- Mobile friendly controls
- Consistent design across modules

## Common Components

### Cards
Used for:
- Dashboard summaries
- Alerts
- Statistics

### Forms
Standard fields:
- Text input
- Dropdown selection
- Date picker
- Time picker
- Number input
- Photo attachment
- Notes

### Buttons
Standard actions:
- Add
- Save
- Edit
- Delete
- Search
- Filter

## Module Screen Pattern
Every module uses:
- Header
- Summary section
- Record list
- Add button
- Search/filter options

## User Experience Rules
- Large readable controls
- Simple navigation
- Confirmation before destructive actions
- Consistent icons and layouts

## Future Ready
Support for:
- Dark mode
- Multiple languages
- Voice input
- Accessibility improvements
