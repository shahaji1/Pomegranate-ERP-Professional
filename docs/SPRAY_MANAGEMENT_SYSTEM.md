# Spray Management System Specification

## Purpose
Create a complete spray recording and management system connected with disease, pest, product, inventory and expense modules.

## Spray Record Fields
- Spray ID
- Date picker
- Time picker
- Plot selection
- Plant stage
- Target disease/pest
- Product selection
- Company (auto-filled)
- Active ingredient (auto-filled)
- Dose
- Unit
- Water quantity
- Tank capacity
- Cost calculation
- Weather condition
- Operator name
- Photos
- Observation notes

## Smart Features

### Product Selection
When product is selected:
- Show company
- Show active ingredient
- Show recommended dose
- Show previous usage history

### Disease/Pest Connection
- Select target problem from knowledge database
- Save treatment history
- Track effectiveness

### Inventory Connection
- Automatically reduce used quantity from stock

### Expense Connection
- Calculate spray cost using product cost and quantity used

## Reports
- Spray history
- Product usage
- Disease-wise treatments
- Cost analysis

## CRUD Support
- Add
- View
- Edit
- Delete/Archive
- Search
- Filter

## Future Ready
Supports adding weather alerts, spray reminders and AI-based recommendations.
