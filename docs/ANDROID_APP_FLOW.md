# Android App Flow Design

## Application Structure

### Main Navigation
- Dashboard
- Farm
- Activities
- Inventory
- Reports
- Settings

## Dashboard
Displays:
- Plant count
- Crop stage
- Today's tasks
- Irrigation status
- Recent activities
- Expense summary
- Alerts

## Universal Add Button
Quick actions:
- Add spray
- Add irrigation
- Add fertigation
- Add expense
- Add purchase
- Add disease observation
- Add harvest record

## Form Controls
- Date picker
- Time picker
- Dropdown selection
- Search suggestions
- Number input
- Photo upload
- Voice notes

## Record Actions
Every module supports:
- Create
- View
- Edit
- Delete
- Search
- Filter
- Export

## User Experience Goal
Simple enough for daily farm use while supporting professional farm management.
