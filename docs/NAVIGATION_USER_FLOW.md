# Navigation and User Flow Specification

## Purpose
Define the complete movement of users through the Android application.

## App Start
Splash Screen
-> Login/Profile (optional)
-> Dashboard

## Main Navigation
Dashboard
- Farm overview
- Alerts
- Quick actions

Farm Management
-> Farm details
-> Plots
-> Plants

Operations
-> Activity entry
-> Spray records
-> Irrigation
-> Fertigation
-> Inventory
-> Expenses
-> Harvest

Knowledge Center
-> Disease library
-> Pest library
-> Product database
-> Company database

Reports
-> Cost analysis
-> Input history
-> Yield reports
-> Profit reports

## Navigation Rules
- Simple user flow
- Minimum steps for daily entries
- Consistent back navigation
- Search available where required
- Permissions ready for future users

## Future Navigation Additions
- Weather center
- Sensor dashboard
- AI assistant
